## Ana metin
Yaklaşık 1162. Moğol bozkırında bir çocuk doğdu. Adı Temüçin'di.

Daha çocukken babasını kaybetti. Kabilesi ailesini yüzüstü bıraktı. Annesi Hö'elün, çocuklarını bozkırın en zor günlerinde ayakta tuttu.

Temüçin her yenilgiden bir ders çıkardı. Eşi Börte kaçırılınca müttefikleriyle birlikte onu geri aldı. Bu olay, yükselişinin dönüm noktası sayılır.

1206'da boylar bir araya geldi ve ona "Cengiz Han" dediler. Terfiyi soya değil yeteneğe bağladı, yazıyı benimsedi, Yam adlı ulak ağını kurdu.

Sonra orduları Çin'den Orta Asya'ya yürüdü. Şehirler düştü. Bu yürüyüş geride çok ağır bir bedel de bıraktı. Hikâyenin o yüzünü unutmamak gerek.

1227'de seferdeyken öldü. Mezarı hâlâ bilinmiyor. Bozkırın çocuğunun attığı temel, ardıllarının döneminde tarihin en büyük bitişik kara imparatorluğuna dönüştü.

Kahraman mı, yıkıcı mı? Belki de ikisinin gölgesinde geçen bir hayat.

const KELIMELER: CaptionWord[] = ANLATIM.flatMap((seg) => {
  const tokenlar = seg.t.split(/\s+/);
  const agirlik = tokenlar.map(
    (tk) => tk.length + (/[.,?!]$/.test(tk) ? 3 : 0) + (/\d/.test(tk) ? 6 : 0),
  );
  const toplam = agirlik.reduce((a, b) => a + b, 0);
  const sureMs = (seg.bit - seg.bas) * 1000;

  return tokenlar.map((tk, i) => {
    const startMs = t;
    t += (sureMs * agirlik[i]) / toplam;
    return { text: tk.toLocaleUpperCase("tr-TR"), startMs, endMs: t };
  });

/** Yavaş Ken-Burns: yumuşak yakınlaşma ve kayma. */
const KenBurns: React.FC<{ src: string; sure: number; hareket: [number, number, number, number] }> = ({
  src,
  sure,
  hareket,
}) => {
  const frame = useCurrentFrame();
  const p = interpolate(frame, [0, sure], [0, 1], { ...CLAMP, easing: Easing.inOut(Easing.sin) });
  const [z0, z1, dx, dy] = hareket;
  const scale = interpolate(p, [0, 1], [z0, z1]);
  const tx = interpolate(p, [0, 1], [-dx, dx]);
  const ty = interpolate(p, [0, 1], [-dy, dy]);
  return (
    <AbsoluteFill style={{ overflow: "hidden", background: "#2a1a10" }}>
      <Img
        src={staticFile(src)}
        style={{
          width: "100%",
          height: "100%",
          objectFit: "cover",
          transform: `translate(${tx}px, ${ty}px) scale(${scale})`,
        }}
      />
    </AbsoluteFill>
  );
};

## 2. Hedef kitle için en önemli bilgiler

Tarihler ve rakamlar kaynaklara göre değişiyor. Sahne yazılarında "yaklaşık" ifadesi kullanılmalı.

1. **Doğum:** Asıl adı **Temüçin**. Doğum yılı tartışmalı (en sık anılan **yaklaşık 1162**; 1155 ve 1167 de geçer, **doğrulanmalı**). Yer: bugünkü Moğolistan'ın kuzeydoğusu, Onon Nehri çevresi. Babası Yesügey, annesi Hö'elün.

4. **Börte ve ittifaklar:** Eşi Börte, Merkitler tarafından kaçırıldı. Temüçin müttefikleri Toğrul Han ve Camuka ile onu geri aldı. Bu olay yükselişinde dönüm noktası sayılır. Büyük oğlu Cuci'nin babalığı hakkında tartışma var; videoda **girilmemeli**.

6. **Yönetim yenilikleri:** Soy yerine liyakata dayalı terfi, yazılı yasa düzeni (*Yasa*; ayrıntıları ve tarihi **doğrulanmalı**), Uygur alfabesinden uyarlanan Moğol yazısı, **Yam** adlı ulak/posta ağı, dinlere görece hoşgörü.
7. **Seferler:** Batı Xia ve Jin (Çin) devletlerine seferler. **1215'te Zhongdu (bugünkü Pekin)** alındı. Harezmşahlar Devleti'ne karşı sefer 1219-1221 arasında yapıldı (Otrar olayı sonrası). Semerkant, Buhara gibi şehirler düştü.

10. **Miras:** Ölümünden sonra oğlu Ögeday han oldu. Torunları döneminde Moğol İmparatorluğu tarihin en büyük bitişik kara imparatorluğu hâline geldi. Bu büyüklük Cengiz Han'ın tek başına değil, **ardıllarının** da eseri; ifade buna dikkat etmeli.
